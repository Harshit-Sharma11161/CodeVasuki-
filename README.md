
# CodeVasuki

### Think. Code. Compete. Improve.

CodeVasuki is a gamified competitive programming platform designed to transform coding practice into an engaging and competitive experience.

CodeVasuki aims to build better programmers through coding challenges, real-time 1v1 battles, skill-based ratings, leaderboards, and tournaments.

## Key Features

- Competitive coding challenges
- Real-time 1v1 coding battles
- Skill-based matchmaking
- Elo-style rating system
- Global, friends, and university leaderboards
- Daily coding challenges and streaks
- University competitions and tournaments
- Programmer profiles and battle history

## Tech Stack

- Frontend: React, Tailwind CSS, Monaco Editor
- Backend: Node.js, Express.js
- Database: MongoDB
- Real-time Communication: Socket.IO
- Code Execution: Judge0
- Authentication: JWT and bcrypt

## Vision

Our goal is to make competitive programming more engaging by combining the learning experience of coding platforms with the competitive ecosystem of online games.

We don't just want users to solve problems.

We want them to become better programmers.
